# pirate.black

An open-source static website for the Pirate Chain community, written in simple HTML, CSS, and JavaScript so anyone can contribute and help maintain it.

**Website:** [s-ftf.github.io/pirate.black](https://s-ftf.github.io/pirate.black/)

To view locally, run this from the project folder:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Then open [127.0.0.1:4173](http://127.0.0.1:4173).

Edit the HTML pages and files in `assets/`, then check local links with `python3 scripts/check-site.py`. Contributions are welcome through issues and pull requests.

See the [maintenance notes and credits](docs/maintenance.md) for data sources, code organization, checks, and hosting details. Licensed under [0BSD](LICENSE); third-party assets retain their own notices.
